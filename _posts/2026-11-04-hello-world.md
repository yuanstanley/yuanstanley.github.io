This is my first post. 🎉

To write a new one, add a Markdown file to the `_posts` folder named like `YYYY-MM-DD-my-post-title.md`, with this at the top:

```
---
layout: post
title: "My post title"
---
```

Then commit and push. It shows up on the home page automatically. (Feel free to delete this post.)
